# Vokrr iOS App

The iOS client project lives in `ios/Vokrr/` and is generated by `scripts/generate_ios_project.py`.

## Current Scope

The iOS app is a backend client. It should talk only to the Vokrr backend, never directly to Home Assistant.

Implemented project assets in the repo:

- `ios/Vokrr/Vokrr.xcodeproj/project.pbxproj`
- `ios/Vokrr/Vokrr/Info.plist`
- `ios/Vokrr/Vokrr/VokrrApp.swift`

## Configure Default Server

Set:

```bash
IOS_DEFAULT_SERVER_URL=https://api.vokrr.com
```

Regenerate:

```bash
python3 scripts/generate_ios_project.py
```

## Build

On macOS with Xcode:

```bash
xcodebuild -project ios/Vokrr/Vokrr.xcodeproj \
  -scheme Vokrr \
  -destination 'platform=iOS Simulator,name=iPhone 16e' \
  build
```

For a physical iPhone:

1. Open `ios/Vokrr/Vokrr.xcodeproj`.
2. Select the `Vokrr` scheme.
3. Select your iPhone.
4. Set your Apple Developer Team under Signing & Capabilities.
5. Run from Xcode.

## Verification

- App can sign in to the Vokrr backend.
- Rooms and devices load from `/api/rooms` and `/api/devices`.
- Device controls call the backend.
- WebSocket reconnects after backend restart.
- The app uses the public backend URL for remote access.
