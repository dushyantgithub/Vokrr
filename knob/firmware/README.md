# Knob Firmware

This directory contains an ESP32/LVGL firmware example scaffold. It is not part of the current production Vokrr Raspberry Pi deployment.

Current production control surfaces are:

- Native Qt/QML Raspberry Pi touchscreen kiosk
- Backend REST/WebSocket API
- Voice listener
- Generated iOS project
